## Como usar en el proyecto

### Via CDN (sin clonar)
```typescript
import { SceneLoader } from "@babylonjs/core/Loading/sceneLoader";

// Cargar modelo directo desde CDN
const result = await SceneLoader.ImportMeshAsync(
  "",
  "https://assets.babylonjs.com/meshes/",
  "fish.glb",
  scene
);
```

### Via clone local
```bash
git clone --depth 1 https://github.com/BabylonJS/Assets.git resources/babylonjs-assets
cp resources/babylonjs-assets/meshes/fish.glb public/models/
```

```typescript
// Cargar desde public/models/
const result = await SceneLoader.ImportMeshAsync(
  "",
  "models/",
  "fish.glb",
  scene
);
```
